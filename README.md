# 🏛️ SICRB - Système d'Information du Conseil Régional

**Frontend moderne et complet pour la gestion institutionnelle.**

## 🚀 Démarrage

```bash
npm run dev
```

Accès: http://localhost:5173

## 👥 Login

- Email: `dg@sicrb.ci` (ou n'importe quel utilisateur)
- Mot de passe: N'importe quoi
- 8 rôles disponibles pour test

## 📦 Modules

✅ Administration (Organigramme, Agents, Élus, Délibérations)
✅ Finance (Budget, Comptabilité, Paie, Trésorerie, Marchés)
✅ Demandes Citoyennes (Soumission, Suivi, Workflows)
✅ Dashboards par rôle (DG, Directeur, Finance, RH)
✅ Workflows & Approvals
✅ Reporting

## 🏗️ Stack

- React 19 + TypeScript
- Vite
- React Router
- CSS Modern (Flexbox/Grid)
- Mock Services
